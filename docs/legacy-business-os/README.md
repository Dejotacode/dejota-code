# Business OS — páginas públicas legadas

As telas `dashboard`, `crm`, `financeiro`, `operacoes`, `propostas`, `onboarding`, `gestao-projetos` e `funil` foram retiradas do build público durante a homologação 5.37.1.

Motivo: essas telas representam operações internas e não devem ser publicadas/indexadas como páginas estáticas. O código foi preservado aqui apenas como referência para uma futura área autenticada (`/app` ou equivalente), protegida por autenticação/autorização real.
