Criar um site pode parecer complicado no começo, mas você não precisa aprender tudo de uma vez.

## 1. Comece pelo HTML

O HTML define a estrutura da página: títulos, textos, links, imagens e outros elementos.

```html
<h1>Meu primeiro site</h1>
<p>Estou começando minha jornada na web.</p>
```

## 2. Use CSS para criar o visual

O CSS controla cores, espaçamentos, tipografia e responsividade.

```css
body {
  font-family: sans-serif;
  line-height: 1.6;
}
```

## 3. Adicione JavaScript quando precisar de interação

JavaScript permite criar menus, filtros, formulários e outras experiências interativas.

## 4. Publique seu projeto

Depois de construir e testar, você pode colocar o site online usando GitHub e uma plataforma de hospedagem como Cloudflare Pages.
