Publicar um site envolve três etapas: preparar o projeto, versionar o código e configurar a hospedagem.

## 1. Teste localmente

Confirme que o projeto funciona antes de publicar.

## 2. Envie para um repositório

Use Git para manter histórico e enviar o projeto para o GitHub.

## 3. Configure o deploy

Conecte o repositório a uma plataforma de hospedagem e faça o primeiro deploy.
